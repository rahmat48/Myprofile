## 💻 Fitur Website Portofolio Ini

Website ini dibangun menggunakan **Vanilla Web Stack murni (HTML5, CSS3, JavaScript ES6+)** tanpa framework berat untuk menjaga performa optimal dan loading instan:

- 🎨 **Desain Elegan Retro-Modern**: Perpaduan tipografi pixel (*Press Start 2P*) dan kenyamanan teks modern (*Inter*).
- 🌓 **Dynamic Theme (Dark & Light Mode)**: Dukungan palet Cream/Beige dan Dark Gold dengan persistensi `localStorage`.
- 🌐 **Dukungan Bilingual (ID & EN)**: Pergantian bahasa instan (Indonesia & English) untuk seluruh konten.
- 📱 **Mobile Optimized**: Komponen Carousel, Card Proyek, dan Hobi didesain responsif tanpa glitch/flicker render di mobile.
- 🔍 **Interactive Lightbox**: Preview resolusi penuh untuk proyek dan sertifikat resmi.
- ⚡ **Zero External Heavy Dependencies**: Animasi mulus berbasis GPU acceleration dan Intersection Observer API.
